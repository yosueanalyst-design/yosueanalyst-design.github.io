Proyectos prácticos

SQL · Excel
Análisis de Ventas por Categoría

Problema: datos de ventas sin organizar, difíciles de leer. Proceso: consultas SQL para agrupar por categoría y período, dashboard en Excel con los resultados. Resultado: visualización clara de qué productos vendían más y en qué épocas.

Python · Pandas
Automatización de Reporte Semanal

Problema: generar un reporte cada semana tomaba demasiado tiempo manual. Proceso: script en Python con Pandas que lee, procesa y exporta automáticamente. Resultado: el reporte se genera solo en minutos, sin intervención manual.

SQL · Python
Segmentación de Clientes

Problema: lista de clientes sin clasificar, todos tratados igual. Proceso: análisis con Python y SQL para agrupar por comportamiento de compra. Resultado: grupos claros de clientes para enfocar mejor las acciones de marketing.

Excel · Power Query
Dashboard de Indicadores Clave

Problema: métricas importantes dispersas en varios archivos. Proceso: consolidación con Power Query y construcción de dashboard en Excel. Resultado: todos los indicadores en un solo lugar, actualizados y fáciles de leer.
